# XQ Academic Personal Website

This repository contains the bilingual static personal website for [XXXXXQ-0206](https://github.com/XXXXXQ-0206).

The site uses a Research Notebook visual language to present research interests in embodied intelligence, personalized multimodal understanding, and agentic systems, along with selected open-source projects, education, and contact details.

## Local Preview

```powershell
python -m http.server 4173
```

Open `http://localhost:4173` in a browser. The language switch changes the complete visible page between English and Simplified Chinese without navigation.

## Scope

The website intentionally does not publish a CV download, unverified publication claims, photography, analytics, or tracking scripts.

## Deployment

GitHub Pages publishes `main` through `.github/workflows/pages.yml` at [XXXXXQ-0206.github.io](https://XXXXXQ-0206.github.io).
